# 🎨 Skribble Multiplayer Game  

A **real-time multiplayer drawing and guessing game** inspired by *Skribbl.io*.  
Built with **React, Node.js, and Socket.IO**, this project allows players to join game rooms, draw on a synchronized canvas, and guess each other’s drawings through live chat.  

---

## 🚀 Features  

- 🎮 **Real-time gameplay** powered by **WebSockets (Socket.IO)**.  
- 🖌️ **Synchronized canvas** where one player draws and others guess.  
- 💬 **Live chat system** integrated with the game for player interactions.  
- 🏠 **Room-based architecture** for private/public games.  
- 🎨 **Responsive and engaging UI** with a landing page and player dashboard.  
- 👥 **Multiple players** can join and play seamlessly.  

---

## 🛠️ Tech Stack  

- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Real-time Communication**: Socket.IO  
- **Database**: (MongoDB / PostgreSQL)  
- **Version Control**: Git & GitHub  

---

## 📦 Installation  

1. Clone the repository  
   ```
   git clone https://github.com/Sharath-shetty28/skribble.git
   cd skribble
2. Install dependencies for both frontend and backend
   ```
   cd client
   npm install
   cd ../server
   npm install
   ```
   3.Start the backend server
   ```
   npm run dev
   ```
   4.Start the frontend
   ```
    cd client
    npm start
   ```
